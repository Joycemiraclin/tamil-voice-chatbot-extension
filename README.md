The Zero-Literacy Support 
System for Welfare Scheme Navigation, an AI-powered 
browser extension designed to overcome the digital divide 
faced by illiterate users. The system provides a seamless, voice
driven interface that enables users to access information about 
government welfare schemes without needing to read or write. 
The architecture is a single-file Chrome Extension utilizing the 
Web Speech API for Tamil-based Speech-to-Text (VTT) and 
Text-to-Speech (TTS). Its intelligence engine, the Google 
Gemini API (Gemini 2.5 Flash), handles contextual 
understanding and generates natural Tamil explanations. The 
extension automatically triggers on .gov.in domains to provide 
real-time scheme information and is slated for future 
expansion to include a Form-Filling Module. This novel 
approach, leveraging advanced AI grounding capabilities, 
promotes digital inclusivity and simplifies access to critical 
social welfare information for marginalized communities.The 
global digital divide severely marginalizes populations with 
zero or low literacy, excluding them from essential government 
welfare scheme information disseminated via text-based web 
portals. This paper introduces the Zero-Literacy Support 
System for Welfare Scheme Navigation, a novel, AI-powered 
browser extension engineered to restore equitable access 
through voice interaction.The solution is implemented as a 
lightweight Chrome Extension that automatically injects a 
minimal UI onto government domains (e.g., .gov.in). 
Performance analysis confirms the chatbot's efficiency, 
yielding a high overall Goal Completion Rate (GCR) of 93% 
and an exceptionally low Escalation Rate (ER) below 2% for its 
target users .
